# P04 LESSONS

## Round 1 (base J 220.03, no improvement)
- `simpa only [..]` -> `simpa [..]` saves 1 token but costs ~70k hb (J worse): full simp set is expensive here.
- `trans_lt` instead of `▸` in the IsFiniteMeasureOnCompacts proof saves ~25k hb but +2 tokens: break-even is ~14k hb per token.
- `Pi.mul_apply` is required (beta of `(g * fun y => ..) x`); `(hm := hle)` and the `hle` have are required.

## Round 2 (no improvement)
- profile.py unusable (meta attr error); measure segments by inserting `fail` and reading `raw` hb in screen logs.
- Cost hotspots: header ~536k, `hc.locallyIntegrable` instance search ~147k (IsLocallyFiniteMeasure (μ.trim hle) ~134k), final simpa ~193k.
- `borelize Y` fails: it replaces the existing MeasurableSpace instance that μ/hle depend on.

## Round 3 (J 220.03 -> 217.71, adopted F_tri)
- `(e).symm.trans $ by ...` -> `e ▸ by ...` saves 3 tokens with ~+9k hb; `▸` on the goal-side equation works for integral_trim.
- Explicitly supplying instances/implicit args (`(μ := μ.trim hle)`, `haveI := isLocallyFiniteMeasure_of_...`) doesn't reduce hb enough to pay for tokens.
- `hf.inner continuous_const` type-mismatches (Continuous.inner isn't the real-inner form here); keep `by fun_prop`.

## Round 4 (no improvement)
- `<|` costs 2 tokens, `$` costs 1, parens cost 2: always prefer `$` over `(...)`/`<|` at tail position.
- `inner_smul_right`/`real_inner_smul_right` and dropping `Pi.mul_apply` all break the simpa normal form; keep `inner_smul_right'` + `Pi.mul_apply`.

## Round 5 (J 217.71 -> 214.73)
- `$` also works in a `haveI : C $ x := ..` type and after `.1`; each saves 1 token at ~0 hb.
- `(⟪f ·, f x⟫_ℝ)` beats `fun y => ⟪f y, f x⟫_ℝ` by 1 token; `↦` vs `=>` and `_` vs named binder are token-neutral.

## Round 6 (J 214.73 -> 213.70)
- `refine` -> `apply` (same tokens) cut ~15k hb deterministically.
- `have := Class.mk fun K hK ↦ ..` gets "instance problem stuck" (measure is a metavariable); fixing it needs as many tokens as the `haveI : C $ μ.trim hle := ⟨..⟩` form.
