C-3 / 공통 하네스 연결

C-4 / 현재 실행 계획

main 공통 OpenAI 호출로 P02 한 회차

main의 budget-trial과 같은 openai_direct.py의 HTTP 호출·단가·응답 정규화를 재사용한다. 모델은 gpt-6.1-sol, high reasoning, Standard tier다. 터미널에서 입력한 키를 메모리로 전달한다.

08

지금 말할 수 있는 것과 남은 범위

확인한 것
  • 수리 모듈을 실제 생성 루프에 연결할 수 있다.
  • main 공통 OpenAI API 경로로 역할별 호출이 실행됐다.
  • 이번 P02의 최종 proof는 원본보다 짧고 HB가 낮다.
  • 최종 proof는 지정 환경에 통과했다.
  • 비용 미확정 시 후속 호출을 차단하고 best를 보존했다.
아직 남은 것
  • 타임아웃 요청의 실제 사용량·청구 내역 확인
  • 대조군 대비 수리 모듈만의 기여도 분리
  • 독립 반복과 다른 문제로의 일반화
  • #37 작성자의 공개 구현 revision과 실제 통합
  • 공식 대회 API 경로·제출·서버 평가 요건 충족
현재 모드는 personal-experiment다. OpenAI 직접 호출은 대회가 요구하는 OpenRouter 경로와 다르다. 지정 Lean·라이브러리 통과는 확인했지만 공식 대회 제출 결과를 뜻하지 않는다.

이 보고서는 조회 시점의 PR과 실행 기록을 합쳐 작성한 정적 보고서다. PR C 본문의 “API 0회 / 실행 전” 문구는 준비 시점 기록이다. 실제 실행 후 결과는 이 보고서의 P02 절과 로컬 원시 파일을 기준으로 읽는다.
