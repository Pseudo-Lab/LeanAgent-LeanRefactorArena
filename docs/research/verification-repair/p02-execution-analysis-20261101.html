최종 증명의 구조와 코드

List.Sublist.subset으로 원래 Subset 목표를 더 강한 Sublist 목표로 바꿉니다. 정규화 증거를 귀납하고, 연결된 리스트는 ih₁.append ih₂로 처리합니다. 사용자 정의 Subset 조합 보조정리를 없애고 동일한 기저 경우를 묶었습니다.

open OldExpressions in
theorem extractedOldExprInVars :
  NormalizedOldExpr post →
  (extractOldExprVars post).Subset
  (Imperative.HasVarsPure.getVars post) := by
  intro h
  apply List.Sublist.subset
  induction h with
  | const | op | bvar | fvar => exact List.nil_sublist _
  | abs h ih => exact ih
  | quant h₁ h₂ ih₁ ih₂ | eq h₁ h₂ ih₁ ih₂ => exact ih₁.append ih₂
  | ite hc ht he ihc iht ihe => exact (ihc.append iht).append ihe
  | app hf he ho ihf ihe =>
    unfold extractOldExprVars
    split
    · exact List.Sublist.refl _
    · next hfalse =>
        exfalso
        cases ho (by constructor)
        apply hfalse
        rfl
    · exact ihf.append ihe

  3. 비용 화면의 용어 분리. 알려진 비용, 미확정 예약, 과거 예약 합, 청구 확정액을 별도 표기합니다. 마지막 호출 비용은 공급자 사용 내역과 대조해야 합니다.
  4. 이후 비교 실험에서 구성요소 효과 분리. 동일 모델·문제·예산에서 수리 비활성, AutoSolver만 활성, 전체 수리를 비교합니다. 독립 반복이 있어야 생성 결과의 변동도 평가할 수 있습니다.
