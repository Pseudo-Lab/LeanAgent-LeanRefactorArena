# 로컬 연구 기법과 반영 현황

2026-11-01 기준. 미커밋 작업에서 얻은 증명 기법·탐색 정책·검증 최적화를 한 문서 묶음으로 정리했다. 기준 main은 `7f9508a85d44c5369f9461222f9904d6a9c01486`이다. 원래 작업 폴더의 HEAD `9323abd`는 이 main의 조상이 아니므로, 그 폴더의 `git status`만으로 신규 기능을 판정하지 않았다.

이 브랜치는 **문서, 읽기 전용 감사 도구, 작은 검증 근거와 증명 예제**를 추가한다. 실험 구현을 기본 하네스에 통합하거나 `submissions/warmup/best/`를 갱신하지 않는다. 기존 유료 실행이나 Lean 측정을 새로 수행한 결과도 아니다.

## 읽는 순서

1. [반영 감사](adoption-audit.md): 무엇이 main에 이미 있고, 무엇이 실험에만 남았는가.
2. [증명 기법](proof-techniques.md): 기존 수학적 아이디어와 새 표현·의무 축약을 구별한다.
3. [하네스와 탐색](harness-techniques.md): v5–v11, 경쟁형 탐색, 검증 재사용의 실제 구현 범위.
4. [실험 비교](experiments.md): 긍정 결과와 실패·미완료 결과를 같은 기준으로 읽는다.
5. [검증과 재현](reproduction.md): 이 문서의 오프라인 검사와 원래 실험 재현의 차이.

정확한 파일 비교는 [Git 감사 JSON](evidence/git-audit.json)에 있다. 코드·설정·문서 대상 **239개 중 10개는 main과 동일, 15개는 다름, 214개는 같은 경로가 main에 없다**. 원시 `runs/` 전체를 센 수치가 아니다. 경로 부재는 같은 아이디어가 다른 코드에 없다는 증명이 아니므로, 위 수학적 기법은 main 증명 본문도 직접 읽어 판정했다.

## 해석 원칙

- **아이디어 존재 / 특정 후보 채택 / 기본 실행 경로 통합 / 모든 지정 환경 검증**은 별개다.
- Length는 증명 소스 토큰 수다. 원시 heartbeat와 `raw // 1000` 환산값을 섞지 않는다.
- 고정된 `T/T0 + H/H0`와 실험별 원본 분모로 판단한다. 현재 champion을 기준으로 표시한 상대 비용 50은 채택 기준이 아니다.
- 코드·장부 검증은 탐색 전략의 일반적 우월성을 입증하지 않는다. 단회·선택된 문제·과거 대조·축소 import의 한계를 함께 적는다.
- 외부 OpenAI 증명은 다른 환경의 참고 자료다. 이번 P06/P11 기법의 특정 외부 증명 직접 이식을 뒷받침하는 기록은 없으므로 OpenAI 고유 기법으로 귀속하지 않는다.

원래 로컬 실행 근거의 주소·해시는 [source-records.json](evidence/source-records.json), 14개 예제의 수치·해시는 [proofs.json](evidence/proofs.json), 비교 수치는 [facts.json](evidence/facts.json)에 보존했다. 대형 라이브러리·요청/응답 원문·자격 증명은 포함하지 않는다.
