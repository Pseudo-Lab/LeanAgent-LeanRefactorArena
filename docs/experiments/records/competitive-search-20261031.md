### 현재 후보군 기준 경쟁형 탐색: 독립 파일럿

사용자가 요청한 `gpt-6.1-sol`, reasoning `high` 설계·풀이 서브에이전트 실험이다. 기존 실행과 최적 증명을 재사용하지 않고, 새 시행마다 원본·허용 문맥·그 시행의 후보만 제공한다.

공통 피드백은 원본 대비 누적 개선율 대신 현재 챔피언과 경쟁 후보를 보여 준다. 공식 비교용 목적값은 `O=T/T0+H/H0`로 고정한다. 한 epoch의 표시 비용은 `100*O/O_anchor`이며, 상대 비용50은 탐색 목표이지 채택 기준이 아니다. 후보군의 Length/HB/목적값 중앙값·범위와 토큰/HB frontier, 최근 실패의 전체 소스와 진단을 함께 유지한다.

#### 시행 범위와 해석

- P01–P03,6개 조건, 각1회:18개 독립 셀. 각 최대12개 후보 평가 묶음이며 실패도 포함한다.

- portfolio의 scout는 처음에는 자기 분기의 후보만 본다. scout-a는 원본 proof를 받지 않고 문장과 문맥에서 시작한다. 서로 같은 후보를 독립 발견해도 각자 평가·집계한다. 합류 후 총12회 안에서 경쟁한다.

- 동일 계열의 개발 문제3개에서 조건당1회인 파일럿이다. 공식 대회 전체 점수, 통계적 우월성, 미관측 문제 일반화로 해석하지 않는다. 환경·실행 시간·유효 시도 수를 함께 보고한다.

#### 해석 범위

각 셀은 독립 초기 문맥의 단회 시행이다. 표의 우열은 이 파일럿의 관찰이며 통계적 우월성·미관측 문제 일반화·공식 대회 점수가 아니다. P01–P03의 제공된 v4.26.0 문맥만 검증한다. 원본이 최선이면 baseline retained로 표시하며 새 독립 최종 검증을 했다고 주장하지 않는다. 추가 golf는 수행하지 않는다.

후보 평가 묶음의 상한만 동일하다. LLM 추론 토큰·사용요금·전체 실행시간은 같게 통제하거나 계측하지 않았다. Codex 서브에이전트로 수행했으며 별도 API 키를 사용하는 모델 호출은 없다. 병렬 자원 경합과 사용자 요청에 따른 순차 실행 전환이 있어 전략 속도에 대한 인과적 비교로 해석하지 않는다.

#### 완료 및 검증

`gpt-6.1-sol`, reasoning `high`로 설계와 풀이를 수행했다. 18개 셀 모두 12회 후보 평가를 완료했다. 원장 기준 총216회, 유효148회·실패68회다. 최초 baseline18회와 독립 최종 검증18회는 후보 예산과 별도다. 유효 후보는 원래 문맥의 plain check와 HB3회 측정을 거쳤으며, 최종18개도 별도로 같은 검증을 통과했다.

기록 검사 (`runs/competitive-search-20261031/audit.json`, 원래 실행 자료)는 동결 입력·프롬프트·평가기 해시, 후보 소스, 원장 연결, scout/merge 예산, 원본을 숨긴 scout 입력, 최종 소스·로그 해시와 측정 중앙값의 일관성을 확인했다. 18개 최종 검증·216회 후보·미완료 평가0개를 확인했다. 시행 전에 공통 컨트롤러의 합성 단위 테스트14개도 통과했다. 이는 v4.26.0에서의 로컬 검증이며 공식 제출 점수는 아니다.

#### 전략별 관찰

- **독립 출발점 portfolio**가 평균 O=0.449443으로 이번 파일럿에서 가장 낮았다. 대조군보다36.32% 낮고 블록 교체보다2.61% 낮았다. P01에서는 대조군보다 나빴고, 평균 차이의 대부분은 P02에서 발생했다. 이 작은 단회 표본으로 일반적 우월성을 주장하지 않는다.
- **큰 블록 교체와 역방향 탐색**은 평균0.461496, 0.471975로 가까웠다. P02에서는 직접 Subset을 다루는 대신 더 강한 Sublist를 증명하고 Subset으로 내려오는 구조가 큰 개선을 만들었다. P03에서는 긴 관계 귀납을 전체 리스트의 정준적 갱신과 교환 정리로 바꾸는 구조가 여러 독립 시행에서 재발견됐다. 전략 이름과 실제 증명 구조는 일대일 대응하지 않는다.
- **발견 후 정제(distill)**는 유효한 메커니즘이었지만 평균 이득은 대조군 대비5.16%였다. P03은 발견 후보 T87/H871584/O0.574960에서 최종 T88/H159822/O0.427068로 바뀌었다. 토큰1개를 더 써도 충분한 HB 절감이 있으면 총비용이 내려갔다. 반면 P02 최종 O1.098601은 구조 탐색군보다 높았다.
- **표현 변환(reencode)만으로 원본부터 시작**한 조건은 평균0.975863으로 대조군보다38.26% 높았다. P03은 HB를92.81% 줄였지만 T162가 남았다. 이 길이에서는 HB가0이어도 O 하한이162/224=0.723214여서 대조군0.441426을 이길 수 없다. 사용자가 지적한 HB 단독 최적화의 한계를 수치로 보여 준다. 강한 구조를 찾은 뒤의 후처리로서의 표현 변환은 이번에 분리 시험하지 않았다.
